# Changelog

Воркфлоу: при каждом релизе бампим `APP_VERSION` в [`app.js`](app.js) и `CACHE` в [`sw.js`](sw.js) одной парой.

## 1.1.1

**Bluetooth-задержка: автоопределение**

- Тоггл «Автоопределение» (по умолчанию ВКЛ) в разделе «Задержка наушников»
- При каждом старте метронома читаем `audioCtx.outputLatency`, конвертируем в мс, применяем как `btLatencyMs`
- В UI отображается «Определено: XXX мс»
- В авто-режиме слайдер и пресеты задизейблены; ручной режим переходит в полноценный контроль через слайдер
- Состояние тоггла и ручное значение хранятся отдельно в `localStorage`

## 1.1.0

**Тренировки + калибровка Bluetooth-задержки**

Тренировки (Phase 1, без слушания микрофона):

- Кнопка «Тренировки» в шапке бургер-меню → фуллскрин со списком сессий
- JSON-схема в [`sessions/`](sessions/), первая сессия — план из исходного PDF
- Walkthrough-экран: автонастройка метронома (BPM / размер / деления / акценты), стикинг, ноты сеткой хэт/мал./бочка, прогресс-таймер, кнопки `←` / `→` / `±5 BPM`
- Свободная игра в блоке заминки — без метронома, только таймер

Калибровка Bluetooth-задержки (ручной режим):

- Раздел «Задержка наушников» в бургер-меню
- Слайдер 0–400 мс с тремя пресетами (Проводные / Bluetooth / AirPods)
- `draw()` сдвигает визуальную вспышку на `btLatencyMs` мс позже звука
- Калибровка на слух при включённом метрономе
- Значение хранится в `localStorage`

## 1.0.8

**Зафиксированы зелёная риска и градиенты на колесе BPM**

- `.wheel-center` и градиентные оверлеи лежали внутри скроллируемого `.bpm-wheel`, поэтому скроллились вместе с тиками и уезжали за viewport (мерцали только на загрузке)
- Решение: обернул колесо в нескроллируемый `.bpm-wheel-wrap`, риска теперь его сосед — привязана к 50% обёртки, не к контенту
- Градиенты заменены на CSS `mask-image` на самой `.bpm-wheel` — маска применяется к viewport-боксу, а не к скролл-контенту

## 1.0.7

**Колесо BPM прокручивается на десктопе**

- Wheel event handler: всегда `preventDefault()` и используется большая из `deltaX`/`deltaY` — раньше горизонтальные тачпад-свайпы проваливались в дефолт
- `mousedown.preventDefault()` чтобы не выделять текст при драге
- Click без драга прыгает колесом к точке клика (плавный scroll)

## 1.0.6

**Высокое колесо BPM + iOS-фикс скролла**

- Контейнер колеса 32px → 72px, тики 20px → 56px, центральная риска во всю высоту
- Боковые градиенты расширены до 100px с плавным `linear-gradient`
- Убран CSS `scroll-snap-type: x mandatory` — на iOS Safari он отбивал маленькие пальцевые движения; snap к ближайшему тику делается в JS через 140 мс debounce после остановки скролла

## 1.0.5

**Чистое колесо BPM**

- Все тики однородные 2×20px, без перепадов высот → нет «ложной горизонтальной линии»
- 8px gap между тиками, шаг шире
- Боковые градиенты 72px с плавным переходом

## 1.0.4

**Колесо BPM + стопки долей**

- BPM-слайдер заменён на горизонтальное колесо тиков с тач, мышью, тачпадом, click-and-drag
- Точки беат-индикатора заменены на стопки 3 точек в стиле Soundbrenner; тап циклит состояние **акцент → доля → тихая → пропуск**
- Новый звук «soft» (700 Hz, в 2 раза тише), скедулер читает per-beat тип из `state.beatTypes`

## 1.0.3

**UI-чистка**

- Подсказка про хоткеи (пробел / T) скрыта на тач-устройствах через `(hover: none) and (pointer: coarse)`
- Версия + кнопка «Обновить» переехали из главного экрана в самый низ бургер-меню

## 1.0.2

**Звук на iOS**

- На iPhone Web Audio мутится физическим silent switch. Лекарство: запустить `<audio>` с тихим `silent.mp3` на лупе — это переводит iOS audio session в `playback`-категорию, которая игнорирует переключатель
- `silent.mp3` сгенерирован через `ffmpeg` (1.3 KB)
- `start()` стал async, ждёт `audioCtx.resume()`, при сбое показывает тост

## 1.0.1

**PNG-иконки вместо SVG**

- На iOS apple-touch-icon стабильно работает только с PNG (SVG поддержан только iOS 17+, нестабильно)
- Сгенерированы три размера (180/192/512) через `sips` из мастер-файла `icon.png` (1920×1920)
- Манифест содержит 192 + 512 (any) и 512 (maskable)

## 1.0.0

**Первая версия**

- Базовый метроном: BPM 30–300, размер до 12/16, деления 1/4/8/16+триоли, акцент на 1-й доле
- Tap tempo, speed trainer, случайные пропуски, 7 встроенных пресетов + свои в `localStorage`
- PWA с офлайном через service worker, кнопка «Обновить» с `SKIP_WAITING` flow
- Бургер-меню с громкостями, тренером, пропусками, точной настройкой размера, пресетами
- Bottom-sheet модалки для размера и делений
- Чёрный фон, лайм акцент, Google Sans, дизайн под референсы (Pinterest mood)
